# Frontier Legends: Arunachal Pradesh, Uncovered

High-fidelity editorial travel website prototype designed for GitHub Pages.

## Run locally

Open `index.html` directly in a browser, or use any simple static server. The prototype uses hash routing, so it works on GitHub Pages without server-side routing configuration.

## Deploy to GitHub Pages

1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the main branch and `/ (root)` folder, then save.
6. Open the generated GitHub Pages URL.

No build step is required.

## Project structure

- `index.html` — document shell
- `styles.css` — responsive editorial design system
- `script.js` — hash routing, interactions, circuit data and prototype states
- `assets/images/` — local client-provided photography only

## Replacing placeholder content later

- Replace circuit copy/data in `script.js`.
- Replace the simulated ILP/map interactions with real integrations if required.
- Insert final video URLs in the Watch the Series section.
- Insert the approved archive URL/QR asset in Discover More.
- Connect the concierge form to a real backend or form service.
